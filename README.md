# Bidri Crafts — live demo

**Open the demo:** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/arunkumarpatil24j2007-cmd/bidricrafts-demo/main/blueprint.json

The whole store (WordPress + WooCommerce + the Bidri Crafts theme and catalogue) runs inside your browser.
It takes about 30–60 seconds to load the first time. Nothing you do is saved, and no real payments are taken.

This repo only holds the demo package. The project source is private.
